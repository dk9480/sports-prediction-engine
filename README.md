### Prerequisites
- Node.js 18+
- Python 3.10+
- PostgreSQL 15+

### Installation

#### 1. Python Service (Port 8000)
```bash
cd python-service
pip install fastapi uvicorn
uvicorn main:app --reload --port 8000
